# 决策规则速查 — 祷告解密

| 能力 | 一句话规则 |
|---|---|
| 把一段经文默想成祷告 | 圣经中的话先提供方向，默想把已经理解的真理带进情绪、关系和行动。 |
| 用主祷文为具体处境祷告 | 主祷文给祷告者一套可反复学习的范例。 |
| 用试金石检视一次祷告 | 凯勒的十二枚试金石分成四组。 |
| 在默想中寻求与上帝相遇 | 经文所说的真理可以由头脑理解进入心里。 |
| 分别练习赞美与感恩 | 赞美聚焦上帝本身可敬、可喜爱的品格和工作，感谢具体领受的恩赐。 |
| 带着恩典认罪并作出回应 | 对具体过失说实话，同时记住赦免白白赐予，也由基督付上代价。 |
| 带着请求、哀告和交托祷告 | 凯勒把具体请求和愿上帝旨意成就放在一起。 |
| 建立可持续的每日祷告 | 日课让读经、祷告和实际生活相连。 |
| 把一首诗篇带进个人或共同祷告 | 诗篇提供表达敬拜、哀告和认罪的语言。 |
| 用奥古斯丁的提问整理所求 | 凯勒借奥古斯丁区分真实需要与人给所求之物放上的重量。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
