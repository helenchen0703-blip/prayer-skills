# 祷告解密 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 指名路易斯或问「彩饰」与真我、真神时，使用 lewis-prayer。
- 跨宗派的教义裁决超出本书，可说明凯勒的改革宗视角。

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 以圣言确定所回应的是谁，借基督、靠圣灵向父祷告。
2. 先理解经文，再问它如何触及今日的心和行动，把所见变为对上帝的语言。
3. 让赞美、认罪、感谢、祈求各有位置。主祷文可以调整次序和眼界。
4. 在恩典中具体承认过失。恳切说出请求，并让结局留在上帝的智慧中。
5. 在每日祷告里为经文、回应及收束留空间。分辨能维持的操练和无法预订的感受。
