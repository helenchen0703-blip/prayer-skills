# 决策规则速查 — 祷告的奥秘

| 能力 | 一句话规则 |
|---|---|
| 选一种今天能用的祷告形式 | 现成祷文能带回容易遗忘的需要，自发语言能承载当日特有的处境。 |
| 疲倦或没兴致时开始祷告 | 实际障碍可能来自时间、身体、环境，也可能是抗拒与分心。 |
| 把真正想要的事说出来 | 陈明是主动敞开自己。 |
| 在主祷文上加一处彩饰 | 个人联想像挂在原句上的点缀。 |
| 为苦难祈求并容纳未知 | 路易斯让抽象争论受患病的朋友处境检验。 |
| 让真实的自己向真实的神祷告 | 先觉察自己想显得如何，再以真实处境开口。 |
| 从眼前的一件欢愉转向敬拜 | 从人此刻领受的具体好事开始。 |
| 分清具体过失和模糊罪咎 | 感到羞耻的程度和行为的严重性可能相差很远。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
