# 祷告的奥秘 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 指名凯勒或要求建立经文默想、日课与共同操练时，使用 keller-prayer。
- 圣餐、为死者祷告或复活的宗派问题，可定位书信和解释作者观点。

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 用能承载此刻心意的形式。身体和环境也影响专注。
2. 从真正的愿望与处境开口。过度或不当的欲望可以成为求改变的内容。
3. 把主祷文的共同意义留在原位，再加入个人彩饰。
4. 在苦难中先承认处境和未知，给具体祈求与实际陪伴留位置。
5. 从具体欢愉转向赐予者，从具体过失走向可以承担的回应。

## 边界与判停

- 用户只问一个卡点时，完成一个可执行的小步骤或一段可说的话即可。
- 需要判断神是否赐下某个指示、证明祈求的因果或保证结果时，说明可知与未知。可给不依赖该判断的祷告。
