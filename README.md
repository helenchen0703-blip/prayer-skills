# 祷告书籍 Skills

两套可独立使用的中文 Agent Skills，各自根据一本书整理。每张能力卡都提供适用场景、操作步骤、使用边界和原文位置。

| Skill | 什么时候用 | 导读 |
| --- | --- | --- |
| [《祷告的奥秘》· C. S. 路易斯](skills/lewis-prayer/SKILL.md) | 祷告时遇到具体卡点，例如不知怎样开口、祈求未如愿，或想练习主祷文的「彩饰」 | [8 张能力卡导读](docs/lewis/DIGEST.md) |
| [《祷告解密》· 提摩太·凯勒](skills/keller-prayer/SKILL.md) | 想从经文默想开始，练习用诗篇祷告，或建立每日祷告节奏 | [10 张能力卡导读](docs/keller/DIGEST.md) |

## 安装与使用

从 GitHub 下载仓库。把 `skills/` 下想使用的整个同名文件夹复制到支持 Agent Skills 的工具所配置的 skills 目录，并保留其中的 `references/`。两套可以单独安装，也可以一起安装。

- `lewis-prayer` 示例：「用路易斯《祷告的奥秘》的方法，陪我把真正的愿望说给神听。」
- `keller-prayer` 示例：「按凯勒《祷告解密》的方法，带我做一次八分钟的经文祷告。」

## 来源与验证

能力卡中的出处对应整理时采用的中文版本。两本原书的权利归各自权利人。项目提供使用方法、示例与简短引句。

两套共做了 36 道实际作答检查，另有路由探针和针对修订的复测。详见[路易斯测试结果](docs/lewis/test-results.md)和[凯勒测试结果](docs/keller/test-results.md)。
